# Luxury Handmade Candles & Olfactory Art

## 1. Project Introduction
Glow & Wax Boutique is a website designed to showcase luxury handmade candles and olfactory art. It provides an elegant and user-friendly platform where customers can explore candle products and learn about the brand.

## 2. Project Objectives
- To create an attractive and user-friendly website.
- To showcase handmade candle products.
- To provide a smooth browsing experience.
- To develop practical frontend and backend development skills.

## 3. Features
- Attractive and modern website design.
- Luxury candle product presentation.
- Easy navigation.
- Responsive layout.
- User-friendly interface.

## 4. Technologies Used
- HTML – Website structure.
- CSS – Styling and layout.
- JavaScript – Interactive functionality.
- Cloudflare – Website deployment.
- GitHub – Project source code management.

## 5. Project Structure
- index.html – Main website page.
- style.css – Website styling.
- script.js – Interactive features.
- README.md – Project documentation.

## 6. How to Run the Project
1. Download or clone the GitHub repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the website.

## 7. Live Website
Cloudflare Deployment: https://glow-and-wax-boutique.glowwaxstudio.workers.dev

## 8. Conclusion
Glow & Wax Boutique is a frontend website project that demonstrates website design, development, and deployment skills. It combines an elegant appearance with a simple user experience.
